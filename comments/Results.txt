Baseline Architecture DefinitionsDirect LLM (Zero-Shot): The language model (e.g., Gemma) generates a response relying entirely on its internal parametric memory. It executes no external queries, making it the baseline for measuring knowledge-cutoff failures and native hallucination rates.Dense Vector RAG: A traditional retrieval-augmented pipeline. Weather reports or forecast summaries are converted into text chunks, embedded into dense vectors, and stored in a vector database. Given a user query, the system performs a cosine similarity search to fetch the top-$k$ textual chunks to append to the prompt before synthesis.ReAct Agent (Reasoning + Acting): An adaptive agent architecture that uses a continuous loop of Thought, Action, and Observation. The model decides which tools to call (e.g., executing a web search, querying a weather API), observes the output, and iterates until it gathers enough information to resolve the user's prompt.WeatherGPT (Target System): A deterministic pipeline that bypasses embeddings entirely. It extracts intent and location schemas directly, triggers the numerical Open-Meteo API, and injects the raw structured JSON into the context window for single-pass synthesis.
